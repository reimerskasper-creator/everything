EVERYTHING. V1 — Track Anything

1. Create a NEW public GitHub repository (e.g. everything-tracker).
2. Upload index.html, sw.js, manifest.webmanifest and icon.svg to the ROOT of the repository.
3. Settings > Pages > Deploy from branch > main > / (root) > Save.
4. Wait a few minutes, then open the published GitHub Pages URL in Chrome.
5. Chrome menu > Add to Home screen > Install.

This is a local-only prototype. No login, cloud sync, encryption or native Android widgets.
Export backups regularly from Settings. Avoid storing sensitive financial or personal details.
